# 喜多ハウジング仕様の図面仕上げ

## 使い方

```
python3 scripts/make_zumen.py 物件.dtx 出力.jww \
    --name "喜多　太郎邸　新築工事" --number 2026001 --date 2026/10/03 \
    [--floor 1] [--wall 160] [--preview 確認.svg]
```

- `--name` 工事名称（物件名）。省略時は DTX の物件名。
- `--number` 工事番号（省略時は枠の 0000000 のまま）。
- `--date` 設計年月日（省略時は今日）。
- `--wall` 壁厚 mm。柱 105 角なら 160、120 角なら 175（図面枠のチェックリストの決まり）。
- `--preview` 表示グループ 1・9・F の用紙範囲を SVG に出す。仕上がりは必ずこれで目視確認する
  （Chromium で PNG にして見る）。

DTX は `wih-dtx` スキルの `scripts/dtx.py` で読む（`extract`）。必要: Python 3、`pip install shapely`。

## 図面枠

`assets/kita_frame.jww`（ユーザーから受け取った喜多ハウジングの図面枠、Jw_cad Ver.7.00 形式、A3）。
1 つのファイルに既存図・プラン①〜④・断熱/基礎計画書などがレイヤグループで入っている。
印刷時の表示グループは枠内の注記どおり（プラン① = 1・9・F）。

| グループ | 名前 | 縮尺 | このスキルで書くもの |
|---|---|---|---|
| 1 | プラン① | 1/100 | レイヤ1 壁の輪郭線（線色2）、レイヤ3 建具、レイヤD 寸法 |
| 9 | プラン①【書き込み】 | 1/100 | レイヤ6 壁のソリッド（凡例「壁」と同じ RGB C0C0C0）、レイヤD 部屋名、レイヤ0 面積表の数値、図面名称（「○○図1F」を置換） |
| F | 共通 | 1/100 | 工事名称（「喜多　太郎邸　改築工事」を置換）、工事番号（「0000000」）、設計年月日（「2025/11/11」） |

用紙上の位置（図寸 mm、用紙中心が原点）:
- 内枠 x −188〜199、y −137.6〜138。タイトル欄は y −137.6〜−123.4。
- 面積表は x 160.7〜199.3。行の y: 敷地 34.6 / 1階 22.6 / 2階 10.6 / 合計 −13.4。
  ㎡ の値は x 174.4 で右揃え、坪の値は x 193.7 で右揃え。
- 図は (−17, 8) を中心に置く（面積表・凡例・タイトル欄を避ける）。

## 枠の決まり（枠内のチェックリストより）
- フォント ＭＳ ゴシック。部屋名・コメント 4 mm、ほかの文字 3 mm。
- 壁の着色は 1/50 でも 1/100 でも壁全体。壁は真壁・大壁を反映し、（真壁）（大壁）の表記は不要。
- 方位記入・文字かぶり確認・増築／減築範囲の記入・各計画書作成は人が行う。

## JWW の扱い（scripts/jww.py）
- ヘッダ（用紙・レイヤ名・色設定など）と図形リストの後ろはバイト列のまま保持し、図形リストだけ読み書きする。
  枠をそのまま読み込んで保存すると元とバイト単位で一致する（確認済み）。
- 対応図形: 線 CDataSen、円弧 CDataEnko、点 CDataTen、文字 CDataMoji、ソリッド CDataSolid。
  ブロック・寸法図形・画像は未対応（この枠には無い）。
- **座標は図寸 mm（実寸 ÷ レイヤグループの縮尺）**。1/100 なら 910 mm は 9.1。
- ソリッドの色は線色 10 + RGB（COLORREF、0x00BBGGRR）。
- 文字は文字種 0（任意サイズ）、v = [始点 x, y, 終点 x, y, 文字種, 幅, 高さ, 間隔, 角度(度)]。

## 描き方の決まり（make_zumen.py）
- 壁: DTX の普通の壁（下がり壁・腰壁は除く）を壁厚で太らせて結合し、建具の位置（開口幅 + 90 mm）を切り抜く。
  輪郭を線で、内側を三角形のソリッドで塗る。
- 造作出窓（DTX の ZDEM）は壁を切り、出幅ぶん外へ箱形の外形を描く。
- 建具: 窓は 3 本線、片開きは扉線＋円弧（勝手口は外開き）、引戸・襖は 2 枚の引違い線、開口枠は何も描かない。
  連窓（DTX で未対応の建具）は描かれない。
- 部屋名: 名前「なし」は書かない。帖数表示の部屋は「(8.0帖)」を下に添える（1 帖 = 910 × 1820）。
  部屋が狭いときは文字を部屋の幅に収まるまで小さくする（下限 2 mm）。
- 寸法線: DTX の寸法線を、寸法補助線・端部の斜線・数値（3 mm、3 桁区切り）で描く。
- 面積: 1 階は DTX の外周領域、2 階は 2 階の部屋の合計。坪 = ㎡ × 0.3025。2 階が無ければ空欄。
  敷地面積・容積率・建蔽率は DTX に情報が無いので書かない（人が記入）。

## 注意
- 出来上がりの JWW は Jw_cad で開いて確認してもらう。表示が崩れたら、どの部分かを聞いて直す。
- 図面枠が更新されたら `assets/kita_frame.jww` を差し替え、上の位置（面積表の行など）とプレースホルダ文字列を確認し直す。
